# 视频脚本：video-studio 项目介绍

- 视频 id：`studio-intro`
- 目录：`src/videos/studio-intro/`
- 配色：紫→粉（`accent: #a78bfa`，`accent2: #f472b6`）
- 预计时长：约 50 秒，6 个场景

## 分镜

### 1. title（TitleScene）
- 画面：小字「项目介绍 · video-studio」，大标题「用代码做\n分享视频」
- 旁白：这是 video-studio，一个用代码做分享视频的工作台。一个仓库，就能维护很多支视频。

### 2. structure（ListScene，第 1/4 步）
- 画面：标题「框架与内容分离」，两张卡片
  - framework：场景原型、动画、配音、字幕，所有视频共用
  - videos/<主题>：每支视频一个目录，只放这支视频的内容
- 旁白：项目分成两部分。framework 是公共引擎，所有视频共用；videos 下每个目录是一支视频，只放自己的内容。

### 3. define（CodeScene，第 2/4 步）
- 画面：标题「一支视频 = 一个 VideoDef」，代码卡展示 VideoDef 的字段
- 旁白：每支视频导出一个 VideoDef，写清楚编号、标题、场景、配音和配色，框架会自动把它注册成一个视频。

### 4. duration（PipelineScene，第 3/4 步）
- 画面：标题「配音决定时长」，四个阶段：写文案 → say 配音 → 测量时长 → 排时间线
- 结论横幅：改了文案，重跑 npm run audio 即可
- 旁白：场景时长不用手写。脚本先用系统语音生成配音，再测出时长写回配置，画面按这个时长排好，音画天然同步。

### 5. render（ExchangeScene，第 4/4 步）
- 画面：标题「预览与导出」，左端「Studio」，右端「MP4」，消息：npm run dev 实时预览 / npx remotion render 导出
- 节点音效：第 78 帧 `ding.wav`
- 旁白：做好之后，用 Studio 实时预览，确认没问题，再一条命令导出成 MP4 文件。

### 6. recap（RecapScene）
- 画面：步骤「新建」「文案」「场景」「配音」「导出」，标题「五步出一支视频」
- 旁白：新建、写文案、配场景、生成配音、导出，五步就能做出一支分享视频。

## 生成步骤

```bash
npm run audio studio-intro                              # 生成配音并回写 audioMeta.json
npx remotion render studio-intro out/studio-intro.mp4   # 导出视频
```
