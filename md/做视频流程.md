# 做视频流程

以 `studio-intro`（video-studio 项目介绍）为例。

## 1. 写视频脚本（可选）

定好主题、配色和每个场景的画面与旁白，例如 `md/视频脚本-项目介绍.md`。不是必需的，但先写好后面会顺很多。

## 2. 新建视频目录

```bash
npm run new studio-intro "video-studio 项目介绍"
```

会从 template 复制一份，生成 `src/videos/studio-intro/`。

## 3. 手动注册

在 `src/videos/index.ts` 里 import 这支视频，并加进 `VIDEOS` 数组。脚手架不会自动做这一步。

## 4. 填写内容

- `narration.json`：每个场景的旁白 `text` 和字幕 `captions`。
- `scenes.tsx`：给每个场景选一种场景模板（Title / List / Code / Pipeline / Exchange / Recap），填数据、排顺序，需要的话加 `sfx` 音效。
- `video.tsx`：可选，用 `makePalette({ accent, accent2 })` 换配色。

`narration.json` 的 key 必须和 `scenes.tsx` 里的 `id` 一一对应。

## 5. 生成配音

```bash
npm run audio studio-intro
```

用 macOS 的 `say` 生成配音，测出时长后写回 `audioMeta.json`，场景时长由这一步决定。以后每次改文案都要重跑。

## 6. 预览和导出

```bash
npm run dev                                              # Studio 实时预览
npx remotion render studio-intro out/studio-intro.mp4    # 导出 mp4
```

第一次跑要先 `npm install`。导出前可以运行 `npx tsc --noEmit` 做一次类型检查。

## 出片后再修改

- 只改了画面：直接重新导出。
- 改了文案：先重跑第 5 步，再导出。
