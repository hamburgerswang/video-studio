# 描述生成视频总结

## 是什么

写一个 Markdown 场景描述文件，运行一条命令，就能得到一支带配音、字幕和音效的 mp4 视频。不用写 React 代码，也不用手动注册或配音。

```bash
npm run make <描述文件.md> <id> "<标题>"
# 例：npm run make md/场景描述-示例.md video-flow "三分钟学会做视频"
```

## 命令做了什么

`scripts/from_md.mjs` 按顺序完成五步：

1. **解析**：读描述文件，检查场景 id、类型和必填字段，出错就指出是哪个场景的哪一行。
2. **生成代码**：在 `src/videos/<id>/` 下写出 `scenes.tsx`、`video.tsx`、`narration.json` 和 `audioMeta.json`。
3. **注册**：把这支视频加进 `src/videos/index.ts` 的 `VIDEOS` 数组，已经注册过就跳过。
4. **配音**：调用 `scripts/gen_audio.py <id>`，生成配音并把每段时长写回 `audioMeta.json`。
5. **导出**：调用 `npx remotion render <id> out/<id>.mp4`。

任何一步失败都会立即停下，不会继续往下执行。

## 我要做的事

1. 复制 `md/场景描述-示例.md`，改成自己的内容。
2. 每个场景写成：`## 场景id | 类型`，下面写画面字段、`旁白`、`字幕`，可选写 `音效`。
3. 运行 `npm run make`，到 `out/<id>.mp4` 看成片。
4. 要修改：改描述文件，再用同一个 id 跑一次。

格式细节见 `md/场景描述格式.md`。

## 可用的场景类型

- **title**：开场标题
- **list**：要点列表
- **code**：代码卡片
- **pipeline**：带箭头的流程
- **exchange**：两端之间来回传消息
- **recap**：结尾回顾

## 规则

- 一个描述文件就是一支视频，文件里写了哪些场景就生成哪些。
- `id` 只能用小写字母、数字和连字符。
- 每个场景必须写 `旁白`。`字幕` 不写时，整段旁白当字幕。
- 第几步 / 共几步自动计算，只算 list、code、pipeline、exchange。
- 命令里的标题作为视频标题；title 场景和 recap 场景没写 `标题` 时也用它。
- 同一个 id 再跑会覆盖之前生成的目录；手写的视频目录不会被覆盖，脚本会报错退出。

## 限制

- 只能用上面 6 种场景模板。像 `browser-journey` 那样的专属场景还是要手写代码。
- 代码卡片里每一行都用默认颜色，不能单独设色。
- 配音依赖 macOS 的 `say`，只能在 Mac 上跑。
- 删掉描述文件里的场景后再生成，旧场景的配音 wav 会留在 `public/audio/<id>/narration/`，不影响视频，可以手动删。

## 相关文件

- `scripts/from_md.mjs`：生成脚本
- `package.json`：`make` 命令
- `md/场景描述格式.md`：格式说明
- `md/场景描述-示例.md`：示例描述文件，已用它生成过 `out/video-flow.mp4`
